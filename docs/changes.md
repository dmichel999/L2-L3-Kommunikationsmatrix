# Änderungswünsche

Hier werden gewünschte, noch nicht umgesetzte Änderungen stichpunktartig notiert.

Sag anschließend "schau dir changes.md an", um die Umsetzung anzustoßen. Nach der Umsetzung wird der jeweilige Eintrag hier als erledigt markiert (Original-Wortlaut bleibt erhalten, nichts wird gelöscht); die Änderung selbst wird wie gewohnt in `releases.md` dokumentiert.
